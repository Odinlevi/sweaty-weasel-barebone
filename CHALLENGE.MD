# Тестовое задание

## Описание
Необходимо создать веб-сервис (только API бэкенд) для работы с клиентами (просмотр,
добавление, редактирование, удаление). Клиентами выступают юридические лица (ЮЛ) и
индивидуальные предприниматели (ИП). ЮЛ могут иметь некоторое количество учредителей.

## Минимально необходимые поля

### Клиент
- ИНН
- Наименование
- Тип (ЮЛ / ИП)
- Дата добавления (заполняется автоматически)
- Дата обновления (заполняется автоматически)
### Учредитель
- ИНН
- ФИО
- Дата добавления (заполняется автоматически)
- Дата обновления (заполняется автоматически)

С типами данных для полей, связями, ограничениями и валидацией необходимо
определиться самостоятельно. Итоговое количество полей может быть другим (большим)
в зависимости от реализации.

## Рекомендации
 - Для разработки использовать платформу ASP.NET Core.
 - Для работы с бэкендом использовать OpenAPI (Swagger).
 - В качестве СУБД использовать на выбор:
   - SQL Express LocalDB (ĸоробочное решение в Visual Studio )
   - MS SQL (на базе docker )
   - PostgreSQL (на базе docker )
 - В качестве ORM использовать Entity Framework Core и подход Code First.
 - Не использовать встроенные механизмы генерации шаблонных контроллеров в
  Visual Studio, т.ĸ. нам необходим ваш личный код для обсуждения и ревью.
 - Загрузить исходный код на любую Git платформу с уникальным названием проекта
  (либо же скрыть из публичного поиска).
 - Если проект будет нестандартным (иметь нюансы по запуску или что-то подобное),
  необходимо приложить файл с описанием.
 - При разработке учитывать будущие возможные задачи по проекту, отразить по
  возможности это в архитектуре приложения, использовать паттерны проектирования,
  творить с душой.
